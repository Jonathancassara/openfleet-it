# OpenFleet IT v0.1.1-alpha.1

## Improvements

- Software operations can be cancelled from the interface.
- Conflicting operations on the same package or target are rejected while one is active.
- Installed software inventory can be exported as CSV or JSON.
- WinGet parser coverage now includes localized, ANSI-formatted and malformed output.
- Product version and update metadata now report `0.1.1-alpha.1`.

## Home preview

The repository also contains the separate `OpenFleet Helper v0.2.0-alpha.1` engineering preview. It offers a read-only HTTPS inventory API with short-lived pairing and client-certificate authentication. The desktop **Home devices** panel now verifies the server fingerprint, performs pairing, stores the client certificate in Windows and loads the remote inventory. Read `docs/HOME-HELPER-ALPHA.md` before testing it.

## Known limitations

- The binaries are unsigned and Windows SmartScreen may warn.
- The Helper artifact includes scripts to install it as an automatic `LocalService` Windows service and create a Private/LocalSubnet-only firewall rule. Disposable-VM installation testing remains required before calling this production-ready.
- Home discovery, revocation and DHCP reconnect testing remain pending.
