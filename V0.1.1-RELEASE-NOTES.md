# OpenFleet IT v0.1.1-alpha.1

## Improvements

- Software operations can be cancelled from the interface.
- Conflicting operations on the same package or target are rejected while one is active.
- Installed software inventory can be exported as CSV or JSON.
- WinGet parser coverage now includes localized, ANSI-formatted and malformed output.
- Product version and update metadata now report `0.1.1-alpha.1`.

## Home preview

The repository also contains the separate `OpenFleet Helper v0.2.0-alpha.1` engineering preview. It offers a read-only HTTPS inventory API with short-lived pairing and client-certificate authentication. It is not installed or enabled by the desktop application yet. Read `docs/HOME-HELPER-ALPHA.md` before testing it.

## Known limitations

- The binaries are unsigned and Windows SmartScreen may warn.
- The desktop console does not yet perform Helper pairing or certificate import.
- The Helper is interactive, not yet a Windows service, and creates no firewall rule.
- Home discovery, revocation, DHCP reconnect and Private-profile firewall automation remain pending.
