# Contributing to OpenFleet IT

OpenFleet IT currently accepts feedback and bug reports through GitHub Issues only.

## Accepted contributions

- Reproducible bug reports
- Feature requests and product suggestions
- Security reports submitted according to `SECURITY.md`

## Code contributions

External pull requests, patches, modified distributions and derivative versions are not accepted or authorized at this time. Please open an issue before proposing any implementation.
